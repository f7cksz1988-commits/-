# 衣橱手账

记录自己有的衣服、护肤品和化妆品，买东西前先查一下，避免买重复。还能保存搭配，并给一个小人换装。

## 功能

- **衣服**：分 9 大类、70 多个小类（上衣、外套、裤子、半身裙、连衣裙、鞋子、包包、配饰、内搭家居），每件可以标春夏秋冬、颜色、品牌、价格、尺码、材质，也可以拍照。
- **护肤 / 彩妆**：记录色号、开封日期、开封后能用几个月、保质期，快过期的会排在最上面提醒你。
- **买前查一查**：选一下想买的东西是什么、什么颜色，马上显示你已经有几件类似的。添加新东西时也会自动提醒。
- **小我（换装）**：可以改小人的肤色、发型和发色，从自己的衣橱里挑衣服穿上，口红和腮红也能用上。可以随机搭一套当季的。
- **搭配**：换装满意了就保存成搭配，标上场合；点「今天穿这套」会记下每件衣服穿了几次。
- **统计与备份**：看看每类有多少件、总共花了多少钱、哪些从没穿过；可以导出和导入备份。

## 怎么用

这是一个网页应用（PWA），不用装任何东西，手机和电脑都能打开，还能「添加到主屏幕」，看起来就像一个 App，没网也能用。

数据**只存在你自己的浏览器里**，不会上传。换手机或清理浏览器之前，记得在右上角「统计与备份」里导出一份备份。

### 用 GitHub Pages 免费发布

1. 打开这个仓库的 **Settings → Pages**。
2. Source 选 **Deploy from a branch**，Branch 选放这些文件的分支，文件夹选 `/ (root)`，保存。
3. 等一两分钟，页面会显示网址，用手机打开它。
4. iPhone：用 Safari 打开 → 分享 → 添加到主屏幕。安卓：用 Chrome 打开 → 菜单 → 添加到主屏幕 / 安装应用。

## 文件

- `index.html`：整个应用（界面、数据、换装小人都在这一个文件里）
- `manifest.webmanifest`、`sw.js`、`icon*.png`、`icon.svg`：让它能装到主屏幕、离线使用
